=== CLI ===
usage: audisor [-h] [--version]
               {scan,inspect,normalize,validate,replay,trace,mcp,install-codex} ...

Evidence-first issue inspection for Codex.

positional arguments:
  {scan,inspect,normalize,validate,replay,trace,mcp,install-codex}
    scan                Create a deterministic ScanReport for one repository.
    inspect             Capture immutable original issue evidence for later
                        validation and replay.
    normalize           Create a semantic Normalize Package from immutable
                        inspection evidence.
    validate            Verify inspection evidence and a Codex Gap Evaluation.
    replay              Compare original inspected evidence with the current
                        resolved repository.
    trace               Build a read-only parent and impact trace from
                        immutable inspection evidence.
    mcp                 Run Audisor as a stdio MCP server.
    install-codex       Register the installed Audisor MCP server with Codex.

options:
  -h, --help            show this help message and exit
  --version             show program's version number and exit
