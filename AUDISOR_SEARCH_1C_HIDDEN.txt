.\.agents\skills\audisor-plan-review\SKILL.md-8-## How it works
.\.agents\skills\audisor-plan-review\SKILL.md-9-
.\.agents\skills\audisor-plan-review\SKILL.md:10:Audisor is a narrow plan qualifier, not a planner or executor. The host detects a **completed valid plan** by validating its structure against the plan-detection schema. When a valid plan is detected, the host calls `aflow_review` **exactly once** with `plan_digest="auto"`. Audisor computes the digest internally, reviews the immutable plan text, and returns a manifest with an outcome.
